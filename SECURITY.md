# Security Policy

## Supported Versions

Only the latest release of Print Pro is currently supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.1.x  | :white_check_mark: |
| < v1.1  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an e-mail to **Mohamed Okash** at [tarekokasha253@gmail.com](mailto:tarekokasha253@gmail.com).

Please include:
* A detailed description of the vulnerability.
* Steps to reproduce the issue.
* Any potential impact or proof of concept.

We will acknowledge your report within 48 hours and attempt to resolve the issue as quickly as possible. Please do not open public issues for security vulnerabilities.
